# 5. Prefetch и голодание воркеров

## Что проверяем

Большой prefetch позволяет одному воркеру заранее забрать несколько задач. Короткие задачи
могут ждать за длинной, пока другой воркер простаивает.

## Настройки

```python
PREFETCH_MULTIPLIER = 4
```

## Шаги

```bash
CONCURRENCY=1 make up
make send ARGS='sleep_task long 60'
make send ARGS='sleep_task short 1 --count 12'
make events
```

Когда распределение коротких задач станет видно, нажми `Ctrl+C`.

## Ожидаем

Распределение коротких задач неравномерно. Часть задач зарезервирована за занятым воркером.
